# Gitalator agent instructions

The owner authorizes local commits at natural completed milestones without asking
for confirmation. Keep commits coherent, validate relevant changes before committing,
and preserve unrelated work. Do not accumulate a long series of completed changes
without committing them.

Push only when explicitly requested and permitted by the workspace access policy.
Use the workspace's shared Beads Rust tracker through `sw-agent beads` for task
tracking when working inside gitalator-ws.
